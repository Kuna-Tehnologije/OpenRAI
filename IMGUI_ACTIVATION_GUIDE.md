# Aktiviranje ImGui Visual UI za OpenRAI Chat

## Trenutno stanje

? Console chat interface radi (`openrai_chat.exe`)  
?? ImGui kod veæ napisan (`src/chat_gui_imgui.cpp`)  
? ImGui library treba instalirati

---

## Korak 1: Instalacija ImGui (vcpkg)

```powershell
# Ako nemaš vcpkg, instaliraj ga:
git clone https://github.com/Microsoft/vcpkg.git C:\vcpkg
cd C:\vcpkg
.\bootstrap-vcpkg.bat

# Dodaj u PATH (jednokratno ili trajno)
$env:PATH += ";C:\vcpkg"

# Instaliraj ImGui s Windows i DirectX 11 podrškom
vcpkg install imgui[core,win32-binding,dx11-binding]:x64-windows

# Integriraj s Visual Studio (opciono)
vcpkg integrate install
```

---

## Korak 2: Update CMakeLists.txt

```cmake
# Dodaj nakon find_package(Threads)
find_package(imgui CONFIG REQUIRED)

# U CUDA_ENABLED bloku, promijeni openrai_chat target:
if(CUDA_ENABLED)
    # ... postojeæi kod ...

    # Chat executable with ImGui
    add_executable(openrai_chat src/main_chat.cpp src/chat_gui_imgui.cpp ${CPP_SOURCES} ${CUDA_SOURCES})
    set_target_properties(openrai_chat PROPERTIES
        CUDA_SEPARABLE_COMPILATION ON
        CUDA_RESOLVE_DEVICE_SYMBOLS ON
    )
    target_include_directories(openrai_chat PRIVATE
        ${CMAKE_CUDA_TOOLKIT_INCLUDE_DIRECTORIES}
    )
    target_link_libraries(openrai_chat PRIVATE 
        Threads::Threads 
        cudart 
        cublas
        imgui::imgui
        d3d11.lib
        dxgi.lib
    )
    target_compile_definitions(openrai_chat PRIVATE OPENRAI_USE_IMGUI)
else()
    # Chat executable with ImGui (non-CUDA)
    add_executable(openrai_chat src/main_chat.cpp src/chat_gui_imgui.cpp ${CPP_SOURCES})
    target_link_libraries(openrai_chat PRIVATE 
        Threads::Threads
        imgui::imgui
        d3d11.lib
        dxgi.lib
    )
    target_compile_definitions(openrai_chat PRIVATE OPENRAI_USE_IMGUI)
endif()
```

---

## Korak 3: Update chat_gui.cpp

Promijeni `src/chat_gui.cpp` da koristi ImGui ili Console mode:

```cpp
// Na vrh fajla dodaj:
#ifdef OPENRAI_USE_IMGUI
    #include "chat_gui_imgui_impl.cpp"  // ImGui implementation
#else
    // Existing console implementation
    // ... (trenutni kod ostaje)
#endif
```

Ili jednostavnije: rebuild æe automatski koristiti `chat_gui_imgui.cpp` umjesto `chat_gui.cpp`.

---

## Korak 4: Rebuild

```powershell
cd C:\dev\openRAI

# Regenerate CMake s vcpkg toolchain
cmake -B build -DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake

# Build
cmake --build build --config Debug --target openrai_chat

# Run ImGui version!
.\build\Debug\openrai_chat.exe
```

## Alternativa: Brža opcija bez vcpkg

Ako ne želiš vcpkg, možeš dodati ImGui kao **git submodule**:

```powershell
cd C:\dev\openRAI

# Add ImGui as submodule
git submodule add https://github.com/ocornut/imgui external/imgui

# Update CMakeLists.txt to include ImGui manually
# (add external/imgui/*.cpp files to build)
```

Ali vcpkg je **lakši** jer automatski setupira sve.
