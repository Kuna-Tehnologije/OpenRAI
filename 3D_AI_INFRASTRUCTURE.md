
## Performance Metrics (3D view)

### HEIGHT (Paralelizacija)
- **Node count**: 500/iter
- **Throughput**: 10,000 node/sec
- **GPU utilization**: CUDA batch @ ~500µs/inference
- **Scalability**: Linear do RAM/GPU limita

### WIDTH (Temporalna)
- **Iteration frequency**: 50ms (20 iter/sec)
- **Memory retention**:
  - Current: 110 samples (5.5 sec lookback)
  - Short-term: 30 samples (top relevance)
  - Vector: 5000 persistent (? lookback via similarity)
- **Learning rate**: Accumulative (svaka iteracija dodaje znanje)

### DEPTH (Semantièka)
- **Embedding dimension**: 32 (balance speed/quality)
- **Vector similarity**: Cosine (normalized dot product)
- **Knowledge graph edges**: Unbounded (grows indefinitely)
- **Goal alignment**: Real-time keyword scoring
